# Hyperliquid: React Native / Expo

A runnable public-price example using `@siebly/hyperliquid-api`. No API key is required.

Use Node.js 24 and npm.

## Run

From this folder:

```sh
npm install
npm start
```

Open the project in a matching Expo Go installation. Press **i** for an iOS simulator or **a** for an Android emulator.

Use **Stop stream** to close the price subscription.

[Follow the complete step-by-step guide](https://sieblyio.github.io/docs/hyperliquid/environments/expo.html).
