# Bybit: Deno

A runnable public-price example using `bybit-api`. No API key is required.

Install Deno first.

## Run

From this folder:

```sh
deno install
deno task start
```

To receive one WebSocket price and close the connection:

```sh
deno task stream
```

[Follow the complete step-by-step guide](https://sieblyio.github.io/docs/bybit/environments/deno.html).
