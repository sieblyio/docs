# Bybit: Node.js / TypeScript

A runnable public-price example using `bybit-api`. No API key is required.

Use Node.js 24 and npm.

## Run

From this folder:

```sh
npm install
npm start
```

To receive one WebSocket price and close the connection:

```sh
npm run stream
```

[Follow the complete step-by-step guide](https://sieblyio.github.io/docs/bybit/environments/typescript.html).
