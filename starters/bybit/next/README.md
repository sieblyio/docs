# Bybit: Next.js

Read public market prices with `bybit-api`. No API key is required for public prices.

Use Node.js 24 and npm.

## Run

From this folder:

```sh
npm install
npm run dev
```

Open `http://localhost:3000/api/price`. A successful response contains the symbol and price as JSON.

[Follow the complete step-by-step guide](https://sieblyio.github.io/docs/bybit/environments/next.html).
