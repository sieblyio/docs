# Bybit: React

A runnable public-price example using `bybit-api`. No API key is required.

Use Node.js 24 and npm.

## Run

From this folder:

```sh
npm install
npm run dev
```

Use **Stop stream** to close the price subscription.

[Follow the complete step-by-step guide](https://sieblyio.github.io/docs/bybit/environments/react.html).
