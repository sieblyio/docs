# Bybit: React Native / Expo

Read public market prices with `bybit-api`. No API key is required for public prices.

Use Node.js 24 and npm.

## Run

From this folder:

```sh
npm install
npm start
```

Use an Expo Go version that supports the Expo SDK in `package.json`. Press **i** for an iOS simulator or **a** for an Android emulator. iOS simulators require macOS and Xcode. Keep Expo Go in the foreground.

Use **Stop stream** to close the price subscription.

[Follow the complete step-by-step guide](https://sieblyio.github.io/docs/bybit/environments/expo.html).
