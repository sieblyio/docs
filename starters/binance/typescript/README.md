# Binance: Node.js / TypeScript

Read public market prices with `binance`. No API key is required for public prices.

Use Node.js 24 and npm.

## Run

From this folder:

```sh
npm install
npm start
```

The script prints a public REST price and exits.

To receive one WebSocket price and close the connection:

```sh
npm run stream
```

[Follow the complete step-by-step guide](https://sieblyio.github.io/docs/binance/environments/typescript.html).
